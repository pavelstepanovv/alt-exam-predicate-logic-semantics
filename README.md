# Семантический переводчик

Логическое ядро для работы с формулами первого порядка: сборка деревьев,
проверка структуры, вычисление истинности и сравнение формул через SAT.
Перевод русского текста пока задаётся вручную.

## Запуск

Нужен Python 3. Используется только стандартная библиотека.
Команды выполняются из папки `semantic_parser`:

```sh
python -m unittest discover -s tests
```

Ограничение размера области для поиска контрпримера:

```sh
python -m src.demo_compare --max-domain-size 2
```

## Состав

- `src/` — сборка, валидация, вычисление формул и SAT-решатель.
- `data/` — словарь предикатов, примеры предложений и тестовые миры.
- `tests/` — автоматические тесты.
- [docs/equivalence_guarantee.md](docs/equivalence_guarantee.md) — ограничения языка и обоснование границы проверки.

## Результаты сравнения

- `equivalent` — достаточная граница полностью проверена, контрпримеров нет.
- `counterexample_found` — найден мир, в котором формулы различаются.
- `no_counterexample_up_to_bound` — различий нет до заданного предела; общей гарантии нет.
- `inconclusive` — исчерпан бюджет вычислений.

Автоматическая граница применяется к формулам без функций и равенства,
с одно- и двухместными предикатами и не более чем двумя свободными
переменными в каждой подформуле. Область объектов непуста.
