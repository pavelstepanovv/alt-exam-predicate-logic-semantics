# Перевод в логику предикатов

Программа переводит русские предложения в формулы логики предикатов.
Используются mT5-small с обученной LoRA-надстройкой и разбор предложения Natasha.
Перед переводом названия заменяются обозначениями классов, свойств, отношений и участников.

Поддерживаются имена, «каждый», «хотя бы один», «ни один», «не каждый»,
отрицания, два однородных свойства, одно относительное придаточное и до двух
квантифицированных участников. Произвольный разговорный текст может переводиться неверно.

## Установка


Сначала скачайте репозиторий:

```powershell
git clone https://github.com/pavelstepanovv/alt-exam-predicate-logic-semantics.git
cd alt-exam-predicate-logic-semantics
```

Затем установите зависимости и скачайте базовую модель:

```powershell
py install 3.10  
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts/download_model.py
```

Базовая модель занимает около 1,2 ГБ и скачивается отдельно с Hugging Face.
Обученная надстройка включена в `models/translator`.
После скачивания программа работает без подключения к сети. При наличии CUDA
используется видеокарта, иначе — процессор.


## Запуск

Откройте `Открыть переводчик.cmd` или выполните:

```powershell
.\.venv\Scripts\python.exe -B -m src.gui
```

Интерфейс: http://127.0.0.1:8765. Остановка — Ctrl+C в окне запуска.
